# PDF & Word Converter Tool

A modern, responsive web application built with HTML, CSS, and JavaScript that allows users to convert and handle documents directly from the browser.

## 🚀 Features
- **PDF to Word Conversion:** Upload a PDF file, extract its text content, and download it instantly as an editable Word document (`.doc`).
- **Interactive UI & Animations:** Powered by smooth CSS transitions and AOS (Animate On Scroll) library.
- **Client-Side Processing:** Runs securely inside your browser using the PDF.js library.

## 🛠️ Technologies Used
- **HTML5 & CSS3** (Flexbox, Grid, Custom Styling)
- **JavaScript (ES6+)**
- **PDF.js** (for parsing and extracting text from PDF files)
